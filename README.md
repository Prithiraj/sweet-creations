# Two Sweet Creations

A mobile-first, static marketing site for Two Sweet Creations in Kissimmee, Florida.

- Evidence-backed content only
- Real licensed editorial photography with explicit replacement notices
- Lightweight origami-inspired Three.js hero enhancement
- CSS fallback and reduced-motion support
- Semantic HTML, accessible controls, responsive images, local-business metadata
- GitHub Pages deployment via Actions

See [PLAN.md](PLAN.md) for the research and design plan and [assets/IMAGE-SOURCES.md](assets/IMAGE-SOURCES.md) for photography rights/status.
