# Two Sweet Creations — Implementation Record

Implementation authorized after approval of [PLAN.md](PLAN.md).

## What was implemented

- Mobile-first single-page static site using semantic HTML, CSS, and small vanilla JavaScript.
- Warm editorial confectionery design system based on the approved cream / cocoa / berry palette.
- Real licensed editorial food photography with visible representative-image disclosure.
- Photography provenance and replacement status documented in [assets/IMAGE-SOURCES.md](assets/IMAGE-SOURCES.md).
- Origami-inspired Three.js hero scene using lightweight folded planes around the real photograph.
- CSS origami fallback when JavaScript, WebGL, reduced-motion preference, small-screen performance policy, or data-saving mode skips Three.js.
- Call and Google Maps CTAs that work without JavaScript.
- Google rating/review-count and listed-hours proof points using the research baseline.
- Responsive image sizing, lazy loading below the hero, keyboard focus states, skip link, semantic headings, and reduced-motion behavior.
- SEO title/description, Open Graph text metadata, Schema.org `Bakery` JSON-LD, robots.txt, and sitemap.xml.
- GitHub Pages deployment workflow at `.github/workflows/pages.yml`.
